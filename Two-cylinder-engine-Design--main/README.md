# Two-Cylinder Engine Design

A detailed two-cylinder engine designed and assembled using **SolidWorks**, demonstrating 3D CAD modeling, mechanical assembly, and motion analysis.

## 📌 Project Overview

This project focuses on the design and assembly of a **two-cylinder engine mechanism** using SolidWorks. The model consists of multiple individually designed mechanical components assembled to demonstrate the interaction and motion of the engine mechanism.

A motion analysis was performed at **50 FPS** to study the dynamic behavior, movement, and interaction of the components during operation.

## ⚙️ Key Features

- Detailed 3D CAD modeling
- Multi-component mechanical assembly
- Two-cylinder engine mechanism
- Crankshaft and connecting rod mechanism
- Gear-driven mechanism
- Mechanical component interaction
- Motion analysis at 50 FPS
- Assembly visualization

## 🛠️ Software Used

- **SolidWorks**
- **SolidWorks Motion Analysis**
